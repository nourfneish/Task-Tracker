## Categories where I found no issue

- Enum handling and unknown-field rejection are solid: `TaskStatus`/`TaskPriority` are typed enums and request models use `extra="forbid"`.
- Title validation trims whitespace and enforces a 200-character limit.
- No backend broad `except` blocks or custom stack-trace exposure were found.
- No secrets or credentials were found in the inspected files; `.env` is ignored by `.gitignore`.
- Frontend task content is HTML-escaped before insertion with `innerHTML`.
- Docker runs the application as a non-root user.
- No Compose files or `.github` workflows were present.

## Assumptions and limits

This was a read-only source audit; no files were changed. I did not inspect deployment infrastructure, Git history, runtime environment variables, or perform a live CVE/database scan. Absence of authentication is confirmed; whether it is an intentional course-only constraint is not documented and therefore not confirmed.
